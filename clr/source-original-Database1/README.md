# Original source (not mine)

This folder is an unmodified copy of the C# project shared by forum user
**betalfa** in a 2015 elitepvpers release, kept here for build reference:
https://www.elitepvpers.com/forum/shaiya-pserver-guides-releases/3596037-release-call-psmagent-commands-via-sql.html

Credit for the original `PSMagent` bridge and the SQL CLR approach goes to
that release. The hardened version actually used by this project is
`clr/Command.cs`, written from scratch on top of the same idea.
